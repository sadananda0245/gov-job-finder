# Roadmap

## Phase 1: Runnable Foundation
- Flask app factory and health routes.
- Environment-based configuration.
- Extension setup for SQLAlchemy, migrations, login, and CSRF.
- Smoke tests.

## Phase 2: Core Data Model
- Users and profiles.
- Trusted job sources.
- Jobs, eligibility rules, saved jobs, and scrape runs.

## Phase 3: Ingestion
- HTML source scraping.
- PDF notification parsing.
- Duplicate detection and source audit trails.
- Daily scheduler.

## Phase 4: Matching and UI
- Eligibility matching explanations.
- Dashboard and filters.
- Saved searches and email notifications.

## Phase 5: Production Readiness
- CI, coverage, structured logging, error pages, and deployment docs.
